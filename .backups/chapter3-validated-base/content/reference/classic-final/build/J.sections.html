Gitleaks

Repère les mots de passe, clés et jetons présents dans le code.

Semgrep

Analyse le code pour repérer des pratiques à risque.

SonarCloud

Vérifie la qualité du code, la couverture des tests et les critères de sécurité configurés.

Dependency-Check

Recherche les vulnérabilités connues dans les bibliothèques Java du backend.

Trivy

Recherche les vulnérabilités connues dans les images des services.

Checkov

Analyse les fichiers d’infrastructure pour repérer des configurations à risque.

Les analyses sont choisies selon le composant : dépendances Java pour le backend, images pour les services conteneurisés, configuration pour l’infrastructure.
